# To-Do List App

A simple yet effective To-Do list application built using HTML, CSS, and TypeScript. This app allows users to manage tasks with options to add, edit, delete, and mark tasks as complete. Tasks are persisted using localStorage so they remain available even after refreshing the page.

## Features:
- **Add Tasks**: Easily add tasks with a simple input field and button.
- **Edit Tasks**: Modify existing tasks by clicking on the "Edit" button next to them.
- **Mark as Completed**: Tasks can be marked as completed with a single click. Completed tasks are highlighted.
- **Delete Tasks**: Tasks can be deleted when they are no longer needed.
- **Local Storage**: All tasks are saved in localStorage, meaning they persist even after a page refresh.
- **Responsive Design**: The app has a mobile-friendly design that adjusts to different screen sizes.

## User Interface:
The user interface is clean and straightforward:
- A header with the title "To-Do List".
- An input box to enter new tasks.
- A button to add tasks.
- A dynamic list of tasks where each task has a corresponding "Edit", "Complete", and "Delete" button.

## Technologies Used:
- **HTML**: Provides the structure for the to-do list application.
- **CSS**: Used for styling and layout of the app, ensuring it looks great on both desktop and mobile devices.
- **TypeScript**: Handles the functionality of adding, editing, marking as complete, deleting tasks, and managing local storage.

## How It Works:
1. **Add a New Task**: Users can type a new task into the input field and press the "Add" button or hit **Enter**.
2. **Edit Task**: By clicking on the edit button next to a task, users can update its text. The task becomes an editable input field when clicked.
3. **Complete Task**: Clicking on the "✔" button will mark a task as completed. It will visually change to a completed state (with a green color).
4. **Delete Task**: Tasks can be deleted by clicking the "✖" button next to them.
5. **Local Storage**: Tasks are saved in local storage, ensuring that tasks persist even after the page is reloaded.
